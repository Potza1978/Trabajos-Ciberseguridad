# Wazuh SOC Lab: Defense Operations & Incident Response

Este repositorio documenta mi laboratorio práctico de ciberseguridad centrado en **Wazuh SIEM**. Aquí desarrollo mis capacidades de detección, respuesta ante incidentes y endurecimiento de sistemas.

## 📂 Contenido del Laboratorio
* **[Proyecto-Wazuh-Hardening](Proyecto-Wazuh-Hardening/):** Implementación de hardening bajo estándares CIS y detección de amenazas con Sysmon y MITRE ATT&CK.

## 🚀 Competencias Demostradas
* **Detección de amenazas:** Uso de reglas de correlación y análisis de eventos críticos.
* **Hardening (SCA):** Evaluación y remediación de configuraciones según Benchmarks CIS.
* **Análisis Forense:** Respuesta ante abuso de herramientas nativas (Living off the Land).
* **Gestión de SIEM:** Centralización de logs y visibilidad integral.

## 📸 Evidencias del Laboratorio
* **Fase de Hardening y Auditoría:** Configuración de firewall, reglas y escaneo SCA (1.png - 5.png).
* **Análisis de Incidentes y Amenazas:** Detección en tiempo real, correlación y métricas de seguridad (6.png - 7.png).
* **Mapeo Táctico y Reporte:** Clasificación MITRE ATT&CK y visualización de resultados finales (8.png - 9.png).

## 🛠️ Detalles Técnicos
* **Canal de Detección:** Microsoft-Windows-Sysmon (Event ID 11).
* **Framework:** MITRE ATT&CK (T1105 - Ingress Tool Transfer).
* **Normativa:** CIS Microsoft Windows 11 Enterprise Benchmark v3.0.0.
